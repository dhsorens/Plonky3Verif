# Aeneas extraction status (2026-06-16)

Fifth periodic survey (see [`../AENEAS.md`](../AENEAS.md)). **Big refactor churn,
net mixed.** A large aeneas trait-method rework (#1114/#1126/#1127) plus 35 charon
commits (now `6f058254`, v0.1.216) **collapsed the old #2 trait-lookup cascade to
zero** (`trait_const_id`/`trait_parent_clause_id`/`trait_type_id` "Could not find"

reproduces** — superseded by #11. The #1 hard blocker is **unchanged**: charon
still stack-overflows (SIGABRT) lifting associated types on `p3-field` (#9),
blocking `field`/`air`/`commit`. Still not usable for a campaign.

## Recommendation

**Churn run — the obstruction landscape was reshaped, not advanced.** The
trait-method rework is a real structural win (the #2 trait-lookup cascade is gone,
error counts down 50–90 %), but it shipped with a regression that nets out
*negative* for usable output:

1. **File #11 (uncaught `CFailure`)** — the top priority. It is a clear aeneas
   regression: input that previously yielded partial Lean now crashes the whole
   run. The fix is likely a missing `catch`/error-recovery boundary in the new
   method-signature path, independent of whatever feature is unsupported.
2. **File #9 (charon stack overflow)** — still the standing #1 hard blocker for
   `field`/`air`/`commit`; untouched by 35 charon commits.
3. **Watch aeneas #1119** — it now tracks the dominant remaining error (closures
   borrowing their env, via `RawDataSerializable`). Once #9/#11 clear, this and
   the closure family (#8) will dominate.
4. The viable path is unchanged: GAT-free, leaf-crate-first, scoped extraction
   (`--exclude RawDataSerializable`) — see [`WORKAROUNDS.md`](WORKAROUNDS.md). The
   full crypto-core via vanilla `--preset aeneas` remains off the upstream roadmap.
5. `keccak` remains closest-to-clean (3 errors, no Plonky3 deps); `maybe-rayon`
   (14) is next. Among `p3-field` dependents, `poseidon2` (203) is now the
   lowest-error crate that still emits Lean.

The hax workspace at `koala-bear/proofs/lean/extraction/` remains the working
verification target.
